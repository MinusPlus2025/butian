# 《补天》旁白配音稿

**用法：** 在 ElevenLabs 打开 Text to Speech。模型选 Eleven Multilingual v2（或 v3），Voice Library 里搜 "Chinese female narrator"，挑一个温柔、沉稳的中文女声。每一行单独生成一条，下载 mp3，按左边的文件名保存到 `~/Desktop/butian/voice/`。

**设置建议：** Stability 约 50，Similarity 约 75，Style 约 20，Speed 0.9。
