# 补天 · 试玩录屏脚本（2–3 分钟）

录屏工具：Mac 按 Cmd+Shift+5 → 选"录制整个屏幕"或"录制所选部分"→ 选项里麦克风选"无"，但要录系统声音的话用 QuickTime 不行，推荐直接用 OBS 或 Cmd+Shift+5（只要画面也可以，声音是加分项）。
浏览器：Chrome 全屏（Cmd+Ctrl+F），打开 https://minusplus2025.github.io/butian/ ，等"开 始"按钮变亮再开始录。

1. 0:00–0:15 停在开始页，鼠标慢慢扫过标题和"相生之序"。
2. 0:15–0:40 点"开 始"，让开场黑屏字幕完整播完，不要跳过。
3. 0:40–1:00 进入山谷，先慢慢转一圈视角，展示灰色的世界、天上的裂缝和上涨的水位条。
4. 1:00–1:30 跟着金色箭头跑到第一块原石（建议选"水"开始，水→木→火→土→金），点击左键抓起，跑回铜炉，点击扔进去，抬头看石头飞上天补裂缝、地面恢复颜色。
5. 1:30–1:45 故意拿错一块（例如补完水后去拿火），扔进炉里，展示"石 碎"和洪水上涨，然后去拿正确的那块。
6. 1:45–2:40 依次补完剩下几块，节奏快一点。
7. 2:40–3:00 最后一块补完，让结局镜头拉升、村民出现、"天成"结算页完整显示，停 3 秒再结束。

提示：如果录坏了，按 Esc →"重新开始"即可重来，不用刷新页面。
